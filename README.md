# rich-life-site

The website for the Rich Life iPhone app: a home page, a privacy policy, and a
support page. Plain HTML and CSS: no frameworks, no JavaScript, no cookies,
no analytics, and nothing loaded from other servers.

- `index.html`: home
- `privacy.html`: privacy policy (App Store Connect → Privacy Policy URL)
- `support.html`: FAQ and contact (App Store Connect → Support URL)
- `styles.css`: shared styles
- `.nojekyll`: tells GitHub Pages to serve the files as they are

No app icon or screenshots yet; the header is text-only until the icon is final.

Published at https://mbj1124.github.io/rich-life-site/
